# SXUWhatEat 登录页视觉优化设计

## 目标

将现有登录页改为无全站导航、单一居中登录卡的沉浸式认证页面。视觉采用已确认的“A · 午夜指挥中心”方向：商务办公的深海军蓝基调，叠加克制的青蓝光晕、网格与代码暗纹，形成神秘但不过度黑客化的代码科技氛围。

登录页品牌文案统一为“SXU·开源之光”，使用山西大学开源软件协会公开站点中的社徽。社徽下载到前端静态资源目录，页面运行时不依赖第三方网络。

## 范围

- 登录页和注册页均隐藏全站顶部导航，避免从注册页返回时重新出现业务路由。
- 认证表单在视口中水平、垂直居中。
- 登录页保留“还没有账号？去注册”入口。
- 注册页复用同一认证背景和卡片视觉，保留现有注册字段、验证码发送和登录入口。
- 不改变登录、注册、验证码接口，不改变 token 存储和登录后跳转逻辑。
- 不调整登录以外的业务页面导航和全局视觉。

## 页面结构

根布局继续挂载 `SiteNav`。`SiteNav` 根据当前路径判断认证路由，在 `/auth/login` 和 `/auth/register` 返回空内容；其他页面保持现有导航行为。

`AuthForm` 保留登录与注册模式，通过模式切换字段和提交逻辑。其展示结构改为：

1. 全屏认证背景容器。
2. 居中的磨砂深色认证卡。
3. 社徽、“SXU·开源之光”和英文辅助标识。
4. 邮箱、密码及注册模式的附加字段。
5. 错误或验证码提示。
6. 主操作按钮和登录/注册链接。

登录页 `Suspense` 加载占位使用同一认证背景，避免加载阶段闪现浅色旧样式。

## 视觉规范

- 背景：深海军蓝渐变，局部青蓝径向光晕。
- 纹理：低透明度网格、少量代码文本和节点装饰，仅作为暗纹，不干扰表单阅读。
- 卡片：深色半透明背景、细描边、中等圆角、柔和深阴影和适量模糊。
- 品牌：社徽置于卡片顶部中央；主标题为“SXU·开源之光”；英文辅助文字使用等宽字体和加大字距。
- 输入框：深色半透明底、清晰标签、青蓝焦点环和高对比输入文字。
- 主按钮：蓝到青的克制渐变，加载和禁用状态沿用现有逻辑。
- 链接与反馈：注册链接使用青色强调；错误提示保持醒目且满足可读性。
- 动效：只使用轻量背景漂移或光晕变化，并尊重 `prefers-reduced-motion`。

## 响应式与可访问性

- 桌面端认证卡最大宽度约 420px。
- 窄屏使用安全边距，卡片宽度不超过视口，注册模式允许页面纵向滚动。
- 使用 `min-height: 100svh` 适配移动浏览器动态视口。
- 保留原生表单标签、正确输入类型、键盘焦点和按钮禁用状态。
- 文本、边框和交互状态保持足够对比度。
- 装饰代码和纹理不进入可访问性树。

## 品牌素材

优先素材为山西大学开源软件协会站点 `https://kungfudaibi.github.io/image/logo.png`。实现时下载到 `frontend/public/branding/`，并通过 Next.js 本地静态路径引用。

若下载失败或素材不可用，才退回山西大学计算机与信息技术学院官方站点标识；当前已确认开源软件协会社徽可访问，因此正常实现不使用回退方案。

## 数据流与错误处理

- 登录提交继续调用 `api.login`，成功后存储 token，并按安全的 `next` 参数或角色跳转。
- 注册继续调用 `api.register`；验证码继续调用 `api.sendEmailVerification`。
- API 错误继续在卡片内展示，不新增弹窗。
- 提交和验证码发送期间继续禁用相应按钮。
- 社徽使用本地文件，避免远程加载失败导致品牌区域空白。

## 验证

- 静态检查：`npm run typecheck`。
- 单元测试：覆盖认证路由识别逻辑，确保认证页隐藏导航、业务页保留导航。
- 构建检查：`npm run build`。
- 浏览器桌面检查：登录页无顶部导航，表单居中，背景和社徽正确，注册入口可见。
- 浏览器移动检查：390px 宽度无横向溢出，注册长表单可滚动，输入和按钮可操作。
- 交互检查：登录错误、加载状态、`next` 跳转和登录/注册切换保持原行为。
